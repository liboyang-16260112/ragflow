# 分块与检索

## 目标与边界

本能力涵盖文本分块的 CRUD 操作与搜索配置管理。分块是文档的最小检索单元，检索配置定义了搜索策略与参数。**不属于本能力的**：数据集的索引管理（见[数据集管理](./dataset.mdx)）、文档的上传与解析（见[文档与摄入](./document-ingestion.mdx)）。

## 运行时流程

```
Client                    API Server                  ES / InfiniKV
  │                           │                           │
  ├─ POST /datasets/{id}/search►                          │
  │                           ├── build query ───────────►│
  │                           │◄── results + scores ──────┤
  │                           ├── merge / re-rank         │
  │◄─ 200 {chunks, scores} ──┤                           │
```

检索支持关键词搜索、向量搜索与混合搜索模式。搜索配置（`/searches`）允许预设检索参数以便重复使用。

## 依赖

- **存储**: Elasticsearch/InfiniKV（分块索引与全文检索）、MySQL（分块元数据）
- **嵌入模型**: 向量检索依赖嵌入模型的可用性
