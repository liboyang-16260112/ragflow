# 智能体

## 目标与边界

本能力涵盖 Agent 模板的创建、查询、更新、删除、会话管理及对话补全。Agent 是具有工具调用能力的高级对话实体。**不属于本能力的**：普通聊天助手（见[会话与对话](./chat-session.mdx)）。

## 运行时流程

```
Client                    API Server                  Agent Engine              LLM / Tools
  │                           │                           │                      │
  ├─ POST /agents/chat/       │                           │                      │
  │   completions ───────────►│                           │                      │
  │                           ├── resolve agent config ──►│                      │
  │                           │◄── agent definition ──────┤                      │
  │                           ├── run agent loop ────────►│                      │
  │                           │                           ├── call LLM ─────────►│
  │                           │                           │◄── tool_use ────────┤
  │                           │                           ├── execute tool ────►│
  │                           │                           │◄── tool_result ────┤
  │                           │                           ├── call LLM ─────────►│
  │                           │                           │◄── final answer ───┤
  │◄── SSE/JSON response ────┤                           │                      │
```

Agent 执行遵循 ReAct（推理-行动）循环：
1. 接收用户问题
2. 调用 LLM 确定下一步行动（回答或调用工具）
3. 如需调用工具，执行并获取结果后返回步骤 2
4. 产生最终答案

## 依赖

- **存储**: MySQL（Agent 模板与会话数据）、Redis（会话状态）
- **外部服务**: LLM 提供商（Agent 配置中指定的模型）、工具服务
