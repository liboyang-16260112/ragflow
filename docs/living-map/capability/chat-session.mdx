# 会话与对话

## 目标与边界

本能力涵盖聊天助手（Chat）的 CRUD、对话会话（Session）的生命周期管理、流式对话补全、OpenAI 兼容接口、思维导图与推荐问题。**不属于本能力的**：Agent 模板的管理与执行（见[智能体](./agent.mdx)）。

## 运行时流程

```
Client                    API Server                  LLM Provider
  │                           │                           │
  ├─ POST /chat/completions ─►│                           │
  │                           ├── resolve session ──┐     │
  │                           │◄── session data ────┘     │
  │                           ├── retrieve chunks ──┐     │
  │                           │◄── chunks ──────────┘     │
  │                           ├── build prompt ──────────►│
  │                           │◄── streaming tokens ──────┤
  │◄── SSE: {delta: true} ────┤                           │
  │◄── SSE: {delta: true} ────┤                           │
  │◄── SSE: {delta: false} ───┤                           │
```

对话补全流程：解析会话上下文 → 检索相关分块 → 构造提示词 → 调用 LLM → 流式返回。

## 依赖

- **存储**: MySQL（助手与会话数据）、Redis（会话状态）、Elasticsearch/InfiniKV（检索）
- **外部服务**: LLM 提供商（OpenAI、Ollama 等，取决于助手配置）
