# 数据集管理

## 目标与边界

数据集是 RAGFlow 中知识库（Knowledge Base）的 API 表示。本能力涵盖数据集的创建、查询、更新、删除、索引构建、标签管理、元数据配置与知识图谱查询。**不属于本能力的**：文档的上传与解析（见[文档与摄入](./document-ingestion.mdx)）、分块的 CRUD 操作（见[分块与检索](./chunk-retrieval.mdx)）。

## 运行时流程

```
Client                    API Server                  Task Queue              Worker
  │                           │                           │                      │
  ├─ POST /datasets ─────────►│                           │                      │
  │◄─ 200 {dataset_id} ──────┤                           │                      │
  │                           │                           │                      │
  ├─ POST /datasets/{id}/index►                           │                      │
  │◄─ 200 (accepted) ────────┤                           │                      │
  │                           ├── enqueue index task ────►│                      │
  │                           │                           ├── dispatch ─────────►│
  │                           │                           │◄── complete ────────┤
  ├─ GET /datasets/{id}/index►                           │                      │
  │◄─ 200 {progress} ────────┤                           │                      │
```

索引构建是异步的——`POST` 请求接受任务后立即返回，调用方通过 `GET` 轮询进度。

## 依赖

- **存储**: MySQL（数据集元数据）、Elasticsearch/InfiniKV（向量索引与全文检索）
- **索引**: 依赖嵌入模型服务的可用性与任务执行器
- **对象存储**: MinIO/S3（如果数据集配置了文件关联）
