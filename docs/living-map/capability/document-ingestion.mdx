# 文档与摄入

## 目标与边界

本能力涵盖文件的解析、文档状态管理、批量操作和摄入任务的启停控制。文档是数据集内的最小可检索单元。**不属于本能力的**：文件系统的浏览与文件夹管理（见[文件管理](./file.mdx)）、数据集的创建与索引（见[数据集管理](./dataset.mdx)）。

## 运行时流程

```
Client                    API Server                  Parser Queue             Parser Worker
  │                           │                           │                      │
  ├─ POST /documents/upload ─►│                           │                      │
  │◄─ 200 {document_id} ─────┤                           │                      │
  │                           │                           │                      │
  ├─ POST /datasets/{id}/     │                           │                      │
  │   documents/parse ───────►│                           │                      │
  │◄─ 200 (accepted) ────────┤                           │                      │
  │                           ├── enqueue parse task ────►│                      │
  │                           │                           ├── dispatch ─────────►│
  │                           │                           │                      ├─ parse
  │                           │                           │                      ├─ chunk
  │                           │                           │                      ├─ embed
  │                           │                           │◄── complete ────────┤
  │                           │                           │                      │
  ├─ GET /documents/{id} ────►│                           │                      │
  │◄─ 200 {status:"COMPLETED"}┤                           │                      │
```

摄入流程包含三个后台阶段：
1. **解析** — 将原始文件转换为结构化文本
2. **分块** — 按配置策略切分文本
3. **嵌入** — 调用嵌入模型生成向量

## 依赖

- **存储**: MySQL（文档元数据）、Elasticsearch/InfiniKV（分块索引）
- **解析引擎**: 原生解析器（`ragflow_deps`）、嵌入模型服务
- **文件存储**: MinIO/S3（上传文件与解析产物）
- **任务队列**: Redis
