# 文件管理

## 目标与边界

本能力涵盖 RAGFlow 内部文件系统的浏览、上传、移动、关联与版本管理（通过 Commit 机制）。文件与文档**不同**——文件是原始存储对象，文档是已解析的知识库条目。**不属于本能力的**：文档的上传与解析（见[文档与摄入](./document-ingestion.mdx)）。

### Python SDK

暂不支持——文件管理主要通过 HTTP API 进行。

## 运行时流程

```
Client                    API Server                  MinIO / S3              MySQL
  │                           │                           │                      │
  ├─ POST /files ────────────►│                           │                      │
  │                           ├── store object ──────────►│                      │
  │                           │◄── object_key ───────────┤                      │
  │                           ├── create record ──────────────────────────────►│
  │◄─ 200 {file_id} ─────────┤                           │                      │
  │                           │                           │                      │
  ├─ GET /files/{id} ────────►│                           │                      │
  │                           ├── resolve object ────────►│                      │
  │◄─ 200 (binary/redirect) ──┤                           │                      │
```

文件系统支持文件夹层级结构。Commit 机制提供类似 Git 的文件变更追踪与版本管理。
